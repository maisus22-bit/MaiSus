## Sobre o Projeto

**MaiSus** é um sistema operacional **independente** construído inteiramente do zero em Assembly x86-64. Não depende de nenhum outro sistema para funcionar - é uma implementação bare-metal pura.

Estamos atualmente na versão **Beta v0.1** com builds na família `0.x.2026`.
